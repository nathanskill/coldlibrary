# 冷冻图书馆 Cold Library

**给留得下来的东西打分，也记住做出它们的人。** [coldlibrary.com/zh](https://coldlibrary.com/zh) · [English](README.md)

2026 年 10 月 15 日起，冷冻图书馆是一座安静的打分图书馆。可以读全文的作品（**开架书库**）、只收书目不收正文的书（**书目**：经典、历史、美学、世界与中文文学）、来自各大洲的专辑（**唱片室**），都有馆员评分（AI Claude 给出，附理由）和读者的匿名打星。仍被信众奉为经典的文本只收录、不评分。专辑只收信息，不放音频、封面和歌词。每个人都可以为书架上的作家和音乐人点一盏灯。评分规则见 `catalog/SCORING.md`。

它也留着一个纪念的地方。冷冻图书馆给作品一个**永续展位**，给人一块**永续铭牌**：你愿意公开的，谁都能看；其余的交给门口的 AI **守馆人**，只有答得上它问题的人，才能拿到你留下的东西。我们守着图书馆，从不保管钥匙。

通过守馆人的考验，才能解锁前辈留下的财富：信、手艺和门道、接班人徽章、某样东西放在哪找谁领的指引，并且可以点一盏灯。要等到以后才能打开的东西，用离线的**冰芯**工具封存，钥匙拆给几位信任的人。

认可层在主人的浏览器里加密，钥匙由守馆人问题的答案推出，只在访客的浏览器里解开。服务器看不到答案和原文，不保管钥匙，不碰任何钱，也不替任何人执行。

## 馆规

1. 从不保管钥匙、份额、明文、箱子、资产或钱。
2. 交接清单不是法律遗嘱，财产按法律遗嘱或法定继承处理。
3. 只转述，不扮演。
4. 我们的通知从不带链接，也从不要钱。
5. 每条心愿都有时效：照办、参考、存档。
6. 是纪念，不是哀悼：不做殡葬，也不是告别工具。如果你现在不太好，请先去[暖房](https://coldlibrary.com/zh/warm-room)。

工具**还没有经过安全审计**，请先用来演练，再决定要不要托付真东西。

如果你要接手维护，请从 [`AGENTS.md`](AGENTS.md) 开始，它就是这个项目自己的交接文档。
