# Held: S-007026 Apollo 11 Guidance Computer source (Luminary 099 / Comanche 055)

Held by the verifier on 2026-10-11. None of the four rights bases in catalog/stacks/README.md is confirmed.

- **Not a US federal government work.** The programs were written by the MIT Instrumentation Laboratory (now Draper), a contractor working under NASA contract. Contractor work does not fall under 17 U.S.C. § 105.
- **No dedication by the author.** Draper and MIT have not published a public-domain dedication or a licence. The "Copyright: Public domain." line in each file header was added by the Virtual AGC transcription project. The Public Domain Mark on github.com/chrislgarry/Apollo-11 was added by the repository maintainer. Neither of them is the author.
- **The project itself hedges.** Virtual AGC (ibiblio.org/apollo, "Licensing") says the Apollo software "is in the public domain, to the best of my non-lawyer understanding". That is a belief, not a grant.
- **Not public domain by age.** The code dates from 1969, and whether it was ever published without notice before 1978 is unsettled.

The README says never to shelve anything we are not sure about.

To reshelve it, we need one of these:
- a written statement from Draper/MIT or NASA that the AGC listings are public domain or openly licensed;
- an authoritative ruling.

Then move the folder back to catalog/stacks/computing/.
