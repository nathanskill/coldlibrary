我想为自然说一句话，为绝对的自由与野性说一句话，以区别于那种仅仅属于市民的自由与教养；我想把人看作自然的居民，看作自然的一部分，而不是社会的一员。我想作一番极端的陈述，但愿这样能说得有力些，因为为文明鼓吹的人已经够多了：牧师、学校委员会，还有你们每一位，都会照管好这件事。

我这一生只遇到过一两个人，懂得散步的艺术，也就是去走一走的艺术；可以说，他们有闲逛的天才。“闲逛”（saunter）这个词的来历很美：据说它源于“中世纪那些在乡间游荡、以前往圣地（à la Sainte Terre）为借口向人乞讨的闲人”，直到孩子们喊起来：“看哪，一个去圣地的人（Sainte-Terrer）！”于是有了闲逛者（Saunterer），去圣地的人。那些散步时从不像他们所自称的那样去往圣地的人，确实只是闲人和流浪汉；而那些真正去了的人，才是好的意义上的闲逛者，我说的就是这一种。不过也有人认为，这个词来自 sans terre，即没有土地、没有家；那么在好的意义上，它就意味着没有特定的家，却处处都同样自在。这正是闲逛得好的秘诀。一个整天坐在屋里不动的人，也许是最大的流浪者；而好的意义上的闲逛者，并不比蜿蜒的河流更像流浪者，那河流一直都在勤勉地寻找通往大海的最短路程。不过我更喜欢第一种说法，它其实也是最可能的来历。因为每一次散步，都是一种十字军东征，由我们心中的某位隐士彼得宣讲，要我们出发，从异教徒手中重新夺回这片圣地。

确实，如今我们只是些胆怯的十字军，连散步的人也是，我们不肯承担坚持不懈、永无止境的事业。我们的远征不过是游览，到了傍晚又绕回我们出发时的那个老炉边。散步有一半只是在重走来路。也许，我们哪怕去走最短的一段路，也应当怀着不朽的冒险精神出发，永不回头，准备好只把我们经过防腐处理的心，作为遗物送回我们荒凉的王国。如果你准备好离开父母、兄弟姐妹、妻儿和朋友，永不再见；如果你已经还清了债务，立好了遗嘱，安排好了一切事务，是一个自由的人，那么你就可以去散步了。

说到我自己的经验，我和我的同伴（因为我有时有个同伴）喜欢把自己想象成一个新的、或者不如说是古老的骑士团的骑士：不是骑马的人，不是骑士，不是骑手，而是步行者，我相信这是一个更古老、更可敬的阶层。曾经属于骑马者的那种骑士精神与英雄精神，如今似乎寓于、或者沉降到了步行者身上：不是游侠骑士，而是游侠步行者。他是一种第四等级，在教会、国家和人民之外。

我们觉得，这一带几乎只有我们在实践这门高贵的艺术；不过，说实话，如果他们自己的说法可以采信，我的大多数同乡有时也很想像我一样散步，可他们做不到。任何财富都买不来这一行所需要的本钱：闲暇、自由与独立。它只能凭上帝的恩典而来。要成为一个步行者，需要上天直接的特许。你必须生在步行者的家族里。步行者是天生的，不是造就的（Ambulator nascitur, non fit）。确实，我的一些同乡还记得、还向我描述过十年前的几次散步，那时他们有幸在林子里迷路了半个小时；但我很清楚，从那以后他们就只在大路上走了，不管他们怎样自称属于这个精选的阶层。毫无疑问，那一刻他们曾被提升起来，仿佛想起了前世的某种存在，那时连他们也是林中人、化外之民。

“他来到绿林之中， / 在一个快活的早晨， / 他听见细细的音符， / 是鸟儿快活的歌声。

“罗宾说，自从我上回来到这里， / 已经过去很久很久； / 我想稍稍射上一射 / 那褐色的鹿。”

我想，我若不是每天至少花四个小时——通常还不止——在林间、在山冈和田野上闲逛，完全摆脱一切俗务，就无法保持身体和精神的健康。你尽可以放心地说：“一便士买你的心思”，说一千镑也行。有时我想起，那些手艺人和店主不但整个上午、而且整个下午都待在店里，那么多人盘着腿坐着——仿佛腿生来是用来坐的，而不是用来站、用来走的——我就觉得，他们没有早就统统自杀，倒是值得称道的。

我这个人，在屋里待上一天就不能不生些锈；有时拖到下午四点，那已是“第十一个钟头”，才偷偷溜出去散步，已经太晚，挽回不了这一天，夜的阴影已开始混进日光里，我便觉得仿佛犯了什么须要赎还的罪过——我承认，我对邻居们的忍耐力感到惊讶，更不必说他们道德上的麻木了：他们一连几个星期、几个月，啊，差不多一连几年，整天把自己关在店铺和办公室里。我不知道他们是什么材料做成的——下午三点钟坐在那里，仿佛那是凌晨三点。波拿巴尽可以谈论凌晨三点钟的勇气，但那比起另一种勇气来就算不了什么：在下午的这个时辰，高高兴兴地坐下来，面对着整个上午你都已认识的那个自己，去困死一支你和它有着那样深厚的同情纽带的守军。我奇怪的是，在这个时候，或者说在下午四五点之间，晨报已嫌太晚、晚报又嫌太早的时候，街头巷尾竟没有响起一声总爆炸，把一大群陈旧的、在屋里养大的念头和怪癖吹散到四面八方去透透气——于是这病也就自己治好了。

女人比男人更被困在家里，她们怎样忍受得了，我不知道；但我有理由怀疑，她们大多数根本就忍受不了。夏日午后，时候还早，我们抖落衣襟上村子的尘土，匆匆走过那些纯粹多立克式或哥特式门面的房子，它们周身带着那样一种安歇的气息，我的同伴便低声说，大概这个时候，屋里的人都上床睡觉去了。正是在这时，我领会到了建筑的美与荣耀：它自己从不上床，而是永远在外面挺立着，为睡着的人守夜。

毫无疑问，气质，尤其是年龄，与此大有关系。人越老，静坐不动、从事室内工作的本事就越大。随着人生的傍晚临近，他的习性也越来越属于黄昏，直到最后，他只在日落之前才出门，半个小时就走够了他需要走的路。

但我所说的散步，和所谓的锻炼毫无相似之处，不像病人定时吃药，不像挥舞哑铃或者椅子；散步本身就是一天的事业和冒险。如果你想锻炼，就去寻找生命的泉源吧。想想看，一个人为了健康挥舞着哑铃，而那些泉水正在远方的牧场上汩汩涌出，他却不去寻找！

此外，你得像骆驼那样散步，据说骆驼是唯一一种边走边反刍的牲口。有位旅人请华兹华斯的女仆领他去看看主人的书房，她回答说：“这里是他的藏书室，可他的书房在外头。”

多在户外，在阳光和风里生活，无疑会使性格生出某种粗糙——会使我们天性中某些较精细的品质上长出一层较厚的表皮，就像脸上和手上那样，又像繁重的体力劳动会夺去双手的一些细腻触感。反过来，待在屋里，也许会使人柔软光滑，更不必说皮肤变薄，同时对某些印象更加敏感。如果阳光少照我们一些，风少吹我们一些，我们对某些于智力和道德的成长十分要紧的影响，或许会更易感受；毫无疑问，把厚皮和薄皮调配得恰到好处，是件微妙的事。但我想，那是一层很快就会脱落的皮屑——天然的疗法，就在夜之于昼、冬之于夏、思想之于经验的比例之中。这样，我们的思想里便会多一些空气和阳光。劳动者长满老茧的手掌，比游手好闲者软绵绵的手指，更熟悉自尊与英雄气概那些更精细的纹理，它们一触，就叫人心头颤动。那种白天躺在床上、自以为白皙、远离经验的晒痕和老茧的东西，不过是多愁善感罢了。

我们散步，自然会走向田野和树林：要是只在花园里或林荫道上散步，我们会变成什么样子呢？甚至有些哲学派别也觉得有必要把树林引到自己身边来，因为他们不到树林里去。“他们种下了小树林和悬铃木的步道”，在向天空敞开的柱廊里作露天的散步（subdiales ambulationes）。当然，如果我们的脚步不能把我们带到树林里去，把脚步引向树林也是枉然。有时我的身体已经走进树林一英里了，精神却还没有到那里，这时我便感到惊慌。在午后的散步中，我很想忘掉上午所有的事务，忘掉我对社会的义务。可有时我很难甩掉村子。某件工作的念头会在我脑子里打转，我不在身体所在的地方——我神不守舍了。我散步，正是想回过神来，回到自己的感官里。如果我想的是树林以外的事，我到树林里来做什么呢？当我发现自己竟被牵扯进哪怕是所谓的善行里——因为这有时也会发生——我就怀疑起自己来，忍不住打个寒战。

我家附近有许多好的散步去处；这么多年来，我几乎天天散步，有时一连走上几天，却还没有把它们走尽。一片全新的景色是一种巨大的幸福，而我至今在随便哪个下午都还能得到它。走上两三个小时，就能把我带到一个陌生的国度，陌生得不亚于我料想此生能见到的任何地方。一座从未见过的农舍，有时就抵得上达荷美国王的领地。事实上，在半径十英里的圆圈之内，也就是一个下午散步所能及的范围之内，风景所蕴藏的可能，与人生的七十年之间，可以发现一种和谐。你永远不会对它完全熟悉。

如今，人类几乎所有所谓的改良，比如盖房子、砍伐森林和所有的大树，都只是让风景变形，让它越来越驯顺、越来越廉价。要是有一个民族，一开始就把篱笆烧掉，让森林留着，那该多好！我看见篱笆烧掉了一半，它们的尽头消失在草原中央；某个俗气的守财奴带着一个测量员在查看他的地界，而天堂已经在他周围降临，他却看不见天使们来来往往，只顾在乐园中央找一个旧桩洞。我再看时，看见他站在一片冥河般的泥沼中央，四周全是魔鬼；他无疑找到了他的地界，三块小石头，那里曾经打下过一根木桩；再走近些看，我看见黑暗之王正是他的测量员。

我能轻轻松松地走上十英里、十五英里、二十英里，多少英里都行，从自家门口出发，不经过一所房子，除了狐狸和水貂过路的地方，也不穿过一条道路：先沿着河，再沿着小溪，然后是草地和林边。我家附近有好几平方英里的地方没有一个居民。从许多座山冈上，我能看见远处的文明和人的住所。农夫和他们的劳作，并不比土拨鼠和它们的洞穴更显眼。人和人的事务，教会、国家和学校，贸易和商业，制造业和农业，甚至政治，这一切当中最叫人惊恐的东西——我很高兴地看到，它们在风景中只占那么一点地方。政治不过是一块狭窄的田地，而那边那条更窄的大路通向它。我有时给旅人指那条路。如果你要去政治的世界，就沿着大路走——跟着那个赶集的人，让他扬起的尘土迷着你的眼，它就会把你径直领到那里；因为政治也只有它自己的一块地方，并没有占满一切空间。我离开它，就像从一块豆田走进森林，转眼就把它忘了。只要半个小时，我就能走到地球表面的某个地方，那里一年到头都没有人站立，因此那里也就没有政治，因为政治不过像一个人吐出的雪茄烟。

村子是道路所趋向的地方，是大路的一种扩展，就像湖是河的扩展。它是身体，道路是它的胳膊和腿——一个三岔路口或四岔路口的地方（trivial or quadrivial），是旅人的通衢和客栈。这个词来自拉丁文 villa；瓦罗把它和 via（道路），或者更古老的 ved 和 vella 一起，推源于 veho，意思是运送，因为 villa 是东西运来运去的地方。靠赶车谋生的人，被说成是 vellaturam facere。由此，显然也来了拉丁文的 *vilis*（卑贱）和我们的 *vile*；还有 *villain*（恶棍）。这让人想到，村民容易陷入哪一种堕落。从他们身边、从他们身上经过的旅行把他们磨得疲惫不堪，他们自己却从不旅行。

有的人根本不散步；有的人在大路上散步；少数人穿过田地散步。道路是为马和生意人修的。相比之下，我不大在道路上走，因为我并不急着赶到它们通往的任何酒馆、杂货铺、马房或者车站。我是一匹能走远路的好马，却不是心甘情愿走大路的驿马。风景画家用人物来标示一条路。他不会这样使用我的身影。我走进的，是古代的先知和诗人，摩奴、摩西、荷马、乔叟，曾经在其中行走过的那种自然。你可以叫它美洲，但它不是美洲：亚美利哥·韦斯普奇也好，哥伦布也好，其余的人也好，都不是它的发现者。关于它，神话里有比我见过的任何所谓的美洲史都更真实的记述。

不过，有几条老路还是走一走有好处的，如今它们差不多已经废弃，倒仿佛真通向什么地方似的。有一条老马尔伯勒路，我想，如今它已经不通往马尔伯勒了，除非它把我带去的地方就是马尔伯勒。我之所以敢在这里说起它，是因为我猜每个镇上都有一两条这样的路。

*老马尔伯勒路*

那里人们曾经挖过钱， / 却从没挖到一个子儿； / 那里有时马歇尔·迈尔斯 / 独自走过， / 还有以利亚·伍德， / 我怕他没干好事： / 再没有别的人， / 除了以利沙·杜根—— / 啊，你这习性野放的人， / 山鹑和野兔， / 你没有别的心事， / 只管去下套子， / 你独自一人过活， / 紧贴着骨头； / 哪里日子最甜， / 就在哪里吃个不停。 / 当春天搅动我的血， / 生出远行的本能， / 我就能踩够砂砾， / 在老马尔伯勒路上。 / 没有人修它， / 因为没有人走它； / 它是一条活路， / 正像基督徒说的那样。 / 那里没有多少人 / 从这门进去， / 只有那个 / 爱尔兰人奎因的客人。 / 它是什么，它是什么， / 不过是那边的一个方向， / 和一点点可能， / 通往某个地方？ / 巨大的石头路牌， / 却不见一个旅人； / 是那些城镇的空墓碑， / 名字刻在它们的顶上。 / 值得去看一看， / 你可能会在哪里。 / 是哪一位国王 / 做了这件事， / 我至今还在纳闷； / 怎样立起、何时立起， / 由哪几位镇务委员， / 古尔加斯还是李， / 克拉克还是达比？ / 它们是一番伟大的努力， / 要永远成为点什么； / 空白的石板， / 旅人可以在那里叹息， / 并用一句话 / 刻下所知的一切， / 好让另一个人去读， / 在他万分需要的时候。 / 我知道一两 / 行诗正合用， / 那样的文字可以立遍 / 这整片土地， / 一个人可以把它记着， / 直到来年十二月， / 到了春天再读一遍， / 在冰雪消融以后。 / 如果你展开想象， / 离开你的住处， / 你就可以环游世界， / 沿着老马尔伯勒路。

目前，在这一带，最好的土地还不是私有财产；风景不归谁所有，散步的人享有相对的自由。但也许有一天，这些土地会被分割成所谓的游乐园，只有少数人能在里面享受一种狭隘而排他的乐趣——到那时，篱笆会越来越多，人们会发明捕人的陷阱和别的机关，把人限制在公路上，而在上帝的大地上行走，会被解释成擅闯某位绅士的领地。独享一样东西，通常就是把自己排除在对它的真正享受之外。那么，让我们在坏日子到来之前，好好利用我们的机会吧。

是什么使我们有时那样难以决定往哪里走呢？我相信自然中有一种微妙的磁力，如果我们不自觉地顺从它，它就会把我们引上正路。往哪条路走，对我们并不是无所谓的。有一条正确的路；但我们很容易因为粗心和愚蠢而走上错路。我们很想走这样一条路：在这个现实的世界里我们还从未走过，而它恰恰完美地象征着我们在内在的、理想的世界里喜爱走的那条路；有时，我们无疑难以选择方向，因为那条路在我们的观念中还没有清晰地存在。

当我出门散步，还拿不准要往哪里去，便听凭本能替我决定，我发现——这也许显得古怪而任性——我最后总是不可避免地落定在西南方，朝着那个方向的某一片树林、草地、荒废的牧场或山冈走去。我的指针落定得很慢——会偏几度，确实并不总是指向正西南，而它这样偏也自有可靠的根据，但它总是落定在正西和西南偏南之间。对我来说，未来就在那边，那一侧的大地似乎更未被耗尽，也更丰饶。框住我散步范围的轮廓，不是一个圆，而是一条抛物线，或者更像那些被认为是一去不回的曲线的彗星轨道，在这里它向西张开，而我的房子占据着太阳的位置。我有时犹豫不决地转来转去，转上一刻钟，直到第一千次决定，我要往西南或者往西走。往东，我只是被迫才去；往西，我才是自由地去。没有什么事务把我引到那边。我很难相信，在东边的地平线后面，我会找到美丽的风景，或是足够的野性与自由。想到要往那边散步，我并不兴奋；但我相信，我在西边地平线上看见的那片森林，一直不间断地向着落日延伸，其中没有哪座城镇重要到足以打扰我。随我住在哪里吧：这一边是城市，那一边是荒野，而我总是越来越远地离开城市，退入荒野。如果我不相信这正是我的同胞们普遍的倾向，我就不会这样强调这个事实。我必须朝俄勒冈走，而不是朝欧洲走。整个国家正朝那个方向移动，我可以说，人类是从东向西前进的。这些年里，我们目睹了一次向东南的迁徙，即澳大利亚的拓殖；但在我们看来这是一种倒退的运动，而且从第一代澳大利亚人的道德和体格来判断，还没有证明是一次成功的试验。东方的鞑靼人认为，西藏以西什么也没有。“世界在那里就到了尽头，”他们说，“再过去只有一片无岸的海。”他们住的地方，是十足的东方。

我们往东去，是为了领会历史，研究艺术和文学的作品，重走人类走过的足迹；我们往西去，则像是走进未来，带着进取与冒险的精神。大西洋是一条忘川，我们渡过它的时候，有机会忘掉旧世界和它的种种制度。如果这一次我们没有成功，在人类到达冥河岸边之前，也许还剩下一次机会；那就是太平洋这条忘川，它有大西洋三倍宽。

一个人竟在他最微不足道的散步里，也这样与人类的总体运动相一致，这有多大意义，在多大程度上证明他与众不同，我不知道；但我知道，某种类似鸟兽迁徙本能的东西——据说在某些时候，它曾影响到松鼠一族，驱使它们作一次普遍而神秘的移动，有人说曾看见它们渡过最宽的河流，每只各乘一片木屑，竖起尾巴当帆，又用同伴的尸体在较窄的溪流上架起桥来——某种类似春天里侵袭家畜的那种狂躁的东西，人们把它归咎于家畜尾巴里的一条虫——无论是常年地还是时不时地，影响着民族，也影响着个人。每当一群野雁在我们镇子上空嘎嘎飞过，总要在某种程度上动摇这里地产的价值；我要是个经纪人，大概会把这种扰动考虑进去。

“那时人们就渴望去朝圣， / 持棕枝的香客要去寻访异乡的海滨。”

我看到的每一次日落，都激起我的渴望，要去一个西方，像太阳落入的那个西方一样遥远、一样美丽。他似乎每天都向西迁徙，引诱我们跟随他。他是各民族追随的伟大的西部拓荒者。我们整夜梦见地平线上那些最后被他的光芒镀上金色的山脊，哪怕它们也许只是雾气。亚特兰蒂斯岛，赫斯珀里得斯的群岛和园子，一种人间的乐园，似乎就是古人的大西部，笼罩在神秘与诗意之中。望着日落的天空，谁没有在想象中看见过赫斯珀里得斯的园子，看见过所有那些寓言的根基呢？

哥伦布比以前任何人都更强烈地感到了向西的倾向。他顺从了它，为卡斯蒂利亚和莱昂找到了一个新世界。那时候的人群，从远处就嗅到了新鲜的牧场。

“此刻太阳已把群山的影子全都拉长， / 此刻已沉入西边的海湾； / 他终于起身，抖了抖他蓝色的斗篷； / 明天去往新鲜的树林和新的牧场。”

在地球上什么地方，能找到一块和我们大部分州所占的面积相当的地区，像这里这样肥沃，物产这样丰富多样，同时又这样适合欧洲人居住呢？米肖只了解其中一部分，他说：“北美的大树种类比欧洲多得多；在合众国，高度超过三十英尺的树种有一百四十多种；在法国，能长到这样高的只有三十种。”后来的植物学家不止证实了他的观察。洪堡来到美洲，是为了实现他青年时代对热带植物的梦想；他在亚马孙的原始森林里看到了它最完美的样子，那是地球上最巨大的荒野，他曾那样雄辩地描写过它。地理学家居约本人就是欧洲人，他走得更远——比我准备跟随他的还要远；不过当他这样说时，我是跟着他的：“正如植物是为动物而造，植物界是为动物界而造，美洲是为旧世界的人而造的……旧世界的人踏上他的路。他离开亚洲的高地，一站一站地向欧洲下行。他的每一步都以一种新的文明为标志，比前一种更高，有更大的发展力量。到了大西洋，他在这片未知的大洋岸边停下来，他不知道它的边界在哪里，于是回过身，看了一会儿自己的脚印。”等他耗尽了欧洲的沃土，重新恢复了元气，“就像在最早的年代那样，再次开始他向西的冒险生涯”。居约就说到这里。

这股向西的冲动碰上大西洋的阻隔，便产生了近代的商业与事业。小米肖在他的《1802 年阿勒格尼山以西游记》里说，在新开拓的西部，人们常问的是：“‘你从世界的哪一处来？’仿佛这些广袤肥沃的地区，自然而然就会成为地球上所有居民相聚的地方和共同的国家。”

借用一个已经废弃的拉丁词，我可以说：Ex oriente lux; ex occidente FRUX。光从东方来；果实从西方来。

英国旅行家、做过加拿大总督的弗朗西斯·黑德爵士告诉我们：“在新世界的北半球和南半球，大自然不仅把她的作品勾勒得规模更大，而且给整幅画涂上了比她描绘和装点旧世界时更明亮、更昂贵的色彩……美洲的天显得无限地更高，天空更蓝，空气更清新，寒冷更凛冽，月亮看上去更大，星星更亮，雷声更响，闪电更耀眼，风更猛，雨更大，山更高，河更长，森林更大，平原更广。”这番话至少可以拿来抵消布丰对世界这一部分及其物产的描述。

林奈很久以前就说过：“Nescio quæ facies læta, glabra plantis Americanis”（我不知道美洲植物的样子里有一种什么样的欢快而光润）；我认为，这个国家没有、或者至多只有很少的 Africanæ bestiæ，也就是罗马人所说的非洲野兽；在这一点上，它也格外适合人居住。我们听说，在东印度的城市新加坡，离市中心三英里之内，每年都有一些居民被老虎叼走；可在北美，旅人几乎在任何地方都可以夜里躺在树林中，不必害怕野兽。

这些都是令人鼓舞的证词。如果这里的月亮看上去比欧洲的大，大概太阳看上去也更大。如果美洲的天显得无限地更高，星星更亮，我相信这些事实象征着这里的居民的哲学、诗歌和宗教有一天可能飞升到的高度。也许终有一天，那非物质的天空在美洲人的心灵看来也会同样更高，那些像星星一样点缀着它的启示也会同样更亮。因为我相信，气候确实是这样反过来作用于人的——就像山间的空气里有某种东西，能滋养精神，给人灵感。在这些影响之下，人不会在智力上和体格上都长得更完美吗？或者，他一生中有多少个雾天，是无关紧要的吗？我相信，我们会更富于想象，我们的思想会像我们的天空一样更清澈、更清新、更空灵——我们的理解会像我们的平原一样更全面、更宽广——我们的智力总体上会像我们的雷电、我们的河流山岳和森林一样，有更宏大的规模——我们的心甚至会在宽广、深邃和壮丽上，与我们的内陆海相称。也许，旅人会在我们的脸上看到某种东西，他说不清是什么，某种 læta 和 glabra，某种欢快而安详的东西。不然的话，世界为什么还要向前走，美洲又为什么要被发现呢？

对美国人，我几乎不必说——

“帝国的星辰取道西行。”

作为一个真正的爱国者，我要是认为乐园里的亚当总的来说比这个国家林区边地的拓荒者处境更好，我会感到羞愧。

我们马萨诸塞人的同情并不局限于新英格兰；尽管我们也许与南方疏远了，我们却同情西部。那里是小儿子们的家园，就像在斯堪的纳维亚人中间，小儿子们到海上去寻找自己的遗产。现在再去研究希伯来文已经太晚了；更要紧的是去理解哪怕是今天的俚语。

几个月前，我去看了一幅莱茵河的全景画。它像一场中世纪的梦。我顺着那条历史悠久的河流漂流而下，那不只是在想象之中：经过罗马人建造、后来的英雄们修补过的桥，经过一座座城市和城堡，它们的名字在我听来就是音乐，每一座都是一个传说的题材。那里有埃伦布赖特施泰因、罗兰塞克和科布伦茨，我只在历史书里知道它们。最让我感兴趣的是那些废墟。从河水里，从覆满葡萄藤的山冈和山谷里，似乎升起一种静悄悄的音乐，仿佛十字军正出发去往圣地。我在魔力的笼罩下漂流着，仿佛被带到了一个英雄的时代，呼吸着骑士精神的空气。

不久以后，我又去看了一幅密西西比河的全景画；我在今天的光线里溯河而上，看见汽船停靠装柴，数着那些正在兴起的城市，凝望着诺伍新近的废墟，看见印第安人向西渡过河去；像先前我曾向摩泽尔河上游望去那样，如今我向俄亥俄河和密苏里河的上游望去，听着迪比克和韦诺娜崖的传说——我想得更多的仍是未来，而不是过去或现在——我看出，这是另一种莱茵河；城堡的地基还有待奠定，著名的桥梁还有待架过河去；我感到这就是英雄时代本身，尽管我们并不知道，因为英雄通常是最朴素、最默默无闻的人。

我所说的西部，不过是野性的另一个名字；我一直准备要说的是：野性之中，保存着世界。每一棵树都把它的根须伸出去，寻找野性。城市不惜任何代价输入它。人们为它耕种，为它航海。从森林和荒野中，来了使人类振作的补药和树皮。我们的祖先是野蛮人。罗慕路斯和雷穆斯被狼哺育的故事，并不是一个没有意义的寓言。每一个兴盛到显赫地位的国家，它的创建者都从类似的野性源泉中汲取了养分和活力。正因为帝国的子孙不是被狼哺育的，他们才被北方森林里那些被狼哺育的子孙征服、取代了。

我信仰森林，信仰草地，信仰玉米在其中生长的夜晚。我们的茶里需要泡进一点铁杉或侧柏。为了力气而吃喝，和仅仅出于贪食而吃喝，是有区别的。霍屯督人理所当然地生吞捻角羚和其他羚羊的骨髓，吃得津津有味。我们北方的一些印第安人生吃北极驯鹿的骨髓，还有其他各个部分，包括鹿角的尖端，只要它们还是软的。在这一点上，也许他们已经抢在巴黎厨师的前头了。他们得到的，是通常被扔进火里烧掉的东西。要造就一个人，这大概比厩里喂养的牛肉和屠宰场的猪肉更好。给我一种野性吧，它的目光任何文明都承受不住——仿佛我们是靠生吞捻角羚的骨髓活着的。

有一些音程，像河边的低地一样，紧挨着林鸫的歌声，我愿意迁徙到那里去——那些还没有拓荒者擅自占住的荒地；我想，我早已适应了那里的水土。

非洲猎人卡明告诉我们，大羚羊的皮，和大多数其他刚被猎杀的羚羊的皮一样，散发出树木和青草最美妙的香气。我愿每个人都那样像一只野羚羊，那样是自然的一部分，以至于他的身体本身就能这样甜美地向我们的感官宣告他的到来，让我们想起他最常出没的那些自然之地。即使捕兽人的外套散发出麝鼠的气味，我也毫无讽刺的意思；在我闻来，它比通常从商人或学者的衣服上散发出来的气味更香。当我走进他们的衣橱，摸摸他们的衣服，我想起的不是他们常去的什么青草平原和开满花的草地，倒是尘土飞扬的商品交易所和图书馆。

晒黑的皮肤可不只是体面而已；对于一个人——一个林中的居民——来说，橄榄色也许比白色更合适。“苍白的白人！”难怪那个非洲人怜悯他。博物学家达尔文说：“一个白人在一个塔希提人身旁洗澡，就像一株被园丁的手艺漂白了的植物，与一株在开阔的田野里茁壮生长的、深绿色的好植物相比。”

本·琼森高呼——

“美的东西离善多么近！”

所以我要说——

“野的东西离善多么近！”

生命与野性相容。最有生气的，就是最野的。它还没有被人驯服，它的存在使人清新。一个不断向前挺进、从不停下劳作的人，一个长得很快、向生活提出无穷要求的人，会发现自己总是在一片新的土地或荒野里，被生活的原料包围着。他会在原始森林倒伏的树干上攀爬。

对我来说，希望和未来不在草坪和耕地里，不在城镇里，而在那些无法穿越的、颤动的沼泽里。从前，当我分析自己为什么偏爱某个我曾考虑买下的农场时，我常常发现，吸引我的只是几平方杆不透水、深不可测的泥沼——它一角上的一个天然洼地。那才是让我目眩的宝石。我从环绕我家乡小镇的沼泽中得到的养料，比从村里精心耕作的园子中得到的多。在我眼里，没有什么花坛比那些茂密的矮生地桂（Cassandra calyculata）更丰美，它们覆盖着地球表面这些柔嫩的地方。植物学只能告诉我生长在那里的灌木的名字，再多就不能了——高丛越橘、圆锥南烛、窄叶山月桂、杜鹃花和加拿大杜鹃——它们全都立在颤动的泥炭藓里。我常想，我愿意让我的房子正面对着这一大片暗红色的灌木丛，不要别的花圃和花境，不要移栽的云杉和修剪整齐的黄杨，甚至不要铺砾石的小径——让这块肥沃的地方就在我的窗下，而不是那几车运来的泥土，只是为了盖住挖地窖时翻出来的沙子。为什么不把我的房子、我的客厅，放在这块地的后面，而要放在那一小堆贫乏的珍奇玩意儿后面，那个对自然和艺术的可怜的敷衍，我叫它我的前院？木匠和泥瓦匠走了以后，收拾一番、弄得像个样子，是件费力的事，尽管这样做既是为了住在里面的人，也同样是为了过路人。最有品味的前院篱笆，在我也从来不是一个令人愉快的研究对象；最精致的装饰，橡子形的柱顶或者别的什么，很快就让我厌倦、厌恶了。那么，就把你的门槛一直修到沼泽的边上吧（尽管那也许不是修干地窖的最好地方），这样，那一边就没有路让市民们进来了。前院不是用来在里面散步的，至多是用来穿过的，而你可以从后门进去。

是的，尽管你也许会认为我乖僻，但如果有人提议让我住在人类的艺术所设计过的最美的花园附近，或者住在一片阴郁的沼泽附近，我一定会选择沼泽。那么，市民们，你们为我所做的一切辛劳，是多么徒劳啊！

外面越是荒凉，我的精神就越是准确无误地随之高涨。给我海洋、沙漠或者荒野吧！在沙漠里，纯净的空气和孤独弥补了湿润和肥沃的缺乏。旅行家伯顿这样说沙漠：“你的精神状态变好了；你变得坦率而热诚，好客而单纯……在沙漠里，烈酒只会引起厌恶。仅仅作为动物活着，就有一种强烈的享受。”那些在鞑靼草原上长久旅行过的人说：“重新进入耕作的土地时，文明的骚动、困惑和混乱压迫着我们，令我们窒息；空气似乎不够我们呼吸了，我们每时每刻都觉得自己快要窒息而死。”当我想要恢复元气时，我就去找最幽暗的树林，最茂密、最无边无际、在市民看来最阴郁的沼泽。我走进沼泽，就像走进一个神圣的地方——一个至圣所。那里有自然的力量，自然的精髓。野生的树林覆盖着处女般的腐殖土——同样的土壤，对人和对树都是好的。一个人的健康，需要他的视野里有多少英亩的草地，就像他的农场需要多少车粪肥一样。那是他赖以为生的硬食。一座城镇之所以得救，靠城里的义人，也同样靠环绕着它的树林和沼泽。一个镇区，上面摇曳着一片原始森林，下面又腐烂着另一片原始森林——这样的镇子，不仅适合种玉米和土豆，也适合为未来的时代培育诗人和哲学家。荷马、孔子和其余的人，就生长在这样的土壤里；从这样的荒野里，走出了那个吃蝗虫和野蜜的改革者。

保护野生动物，一般意味着要为它们造一片森林，让它们居住或出没。人也是这样。一百年前，人们在我们的街上卖从我们自己的树林里剥下的树皮。我想，在那些原始而粗犷的树木的样子里，就有一种鞣制的成分，能使人们思想的纤维变得坚韧而结实。啊！想到我家乡村子这些相对堕落的日子，我已经不寒而栗了：如今你收集不到一车厚度像样的树皮，我们也不再出产焦油和松节油了。

文明的民族——希腊、罗马、英格兰——一直靠着那些古时候就在原地腐烂的原始森林维持着。只要土壤没有耗尽，它们就能存续。唉，人类的文化啊！一个民族，当它的腐殖土耗尽了，被迫用祖先的骨头来做肥料时，就没有多少可指望的了。到那时，诗人只能靠他自己多余的脂肪维持，哲学家则落到屈膝跪地、啃自己骨髓的地步。

据说美国人的任务是“耕作处女地”，而且“农业在这里已经呈现出别处所不知道的规模”。我想，农夫之所以取代了印第安人，正是因为他开垦了草地，从而使自己更强壮，在某些方面也更自然。前几天，我为一个人测量一条一百三十二杆长的直线，它穿过一片沼泽，沼泽的入口处真可以写上但丁在地狱入口处读到的那句话——“进来的人，抛弃一切希望吧”——也就是说，抛弃再出去的希望；有一次，我看见我的雇主真的陷到了脖子，在他自己的产业里游泳逃命，尽管当时还是冬天。他还有另一片类似的沼泽，我根本没法测量，因为它完全在水下；尽管如此，说到第三片沼泽，那片我从远处测量过的，他却出于本性对我说，不管给他什么报酬，他都不会出让它，因为里面有烂泥。那个人打算在四十个月之内，在整片沼泽四周挖一圈环沟，用他铁锹的魔力把它开垦出来。我提到他，只是把他当作某一类人的典型。

我们赖以赢得最重要的胜利的武器，应当作为传家宝父子相传的，不是剑和矛，而是砍灌木的刀、切草皮的铲、铁锹和沼地锄，上面锈着许多块草地的血，染着许多场苦战的田野的尘土。连风也把印第安人的玉米地吹进了草地，指出了一条他没有本事去走的路。他用来在土地上掘壕固守的工具，不过是一只蛤壳。而农夫却有犁和锹作武装。

在文学中，吸引我们的只有野性。乏味不过是驯顺的另一个名字。让我们欣喜的，是《哈姆雷特》和《伊利亚特》里，一切经典和神话里，那种不是在学校里学来的、未开化的、自由而野性的思想。正如野鸭比家鸭更迅捷、更美丽，野性的思想——那只绿头鸭——也是这样，它在降落的露水中，振翅飞过沼泽的上空。一本真正的好书，是一种自然的东西，就像在西部的草原上或东方的丛林里发现的一朵野花，出乎意料、不可思议地美丽而完满。天才是一道使黑暗显形的光，像闪电的一闪，也许会把知识的殿堂本身击得粉碎——而不是在人类的炉边点燃的一支细烛，在平常白昼的光亮面前就黯然失色。

英国文学，从吟游诗人的时代到湖畔诗人——包括乔叟、斯宾塞和弥尔顿，甚至莎士比亚——都没有吐露出一种十分清新的、在这个意义上是野性的调子。它本质上是一种驯顺的、文明的文学，映照着希腊和罗马。它的荒野是一片绿林，它的野人是一个罗宾汉。那里有许多对自然的亲切的爱，却没有多少自然本身。它的编年史告诉我们，它的野兽是什么时候灭绝的，却没有告诉我们，它里面的野人是什么时候灭绝的。

洪堡的科学是一回事，诗是另一回事。今天的诗人，尽管有科学的一切发现和人类积累的学问，比起荷马来，并不占什么优势。

表达自然的文学在哪里？能叫风和溪流为他效劳、替他说话的人，才是诗人；他把词语钉回它们原始的意义上，就像农夫在春天把被冰冻顶起的木桩重新打下去；他每用一个词，就重新推究一次它的来历——把它们移植到他的书页上，根上还带着泥土；他的词语那样真实、清新、自然，即使它们半闷死在图书馆里两张发霉的书页之间，也仿佛会像春天来临时的花蕾一样舒展开来——啊，会在那里，为忠实的读者，与周围的自然相应和，年年依其本性开花结果。

我不知道有什么诗可以引用，能充分表达这种对野性的渴望。从这一面去看，最好的诗也是驯顺的。在任何文学里，无论古代的还是现代的，我都不知道到哪里去找一种能让我满意的记述，记述那连我也熟悉的自然。你会看出，我要求的是任何奥古斯都时代或伊丽莎白时代，总之是任何文化都不能给的东西。神话比任何东西都更接近它。希腊神话扎根于其中的自然，至少比英国文学扎根于其中的自然肥沃多少啊！神话是旧世界在它的土壤耗尽之前、在幻想和想象染上枯萎病之前所结出的庄稼；凡是它原初的活力尚未衰减的地方，它至今仍结出这样的庄稼。其他一切文学，都只像遮蔽我们房屋的榆树那样存续；而神话就像西方群岛上那棵巨大的龙血树，和人类一样古老；无论人类是否长存，它都会同样长存；因为其他文学的衰败，正是它赖以繁茂的土壤。

西方正准备把它的寓言加到东方的寓言上去。恒河、尼罗河和莱茵河的河谷已经结出了它们的庄稼，亚马孙河、拉普拉塔河、奥里诺科河、圣劳伦斯河和密西西比河的河谷将会出产什么，还有待观察。也许，经过许多个时代，当美国的自由已经成为过去的一个虚构——正如它在某种程度上是现在的一个虚构——世界的诗人们会从美国的神话中得到灵感。

即使是野人最野的梦，也并不因此就不那么真实，尽管它们也许不合今天英国人和美国人中间最通行的那种感觉，也就是常识的口味。并不是每一条真理都能讨常识的喜欢。自然为野生的铁线莲留了一个位置，也为卷心菜留了一个位置。有些真理的表达是追忆性的——有些只是像俗话说的那样“合乎情理”——有些是预言性的。甚至某些形式的疾病，也可能预言着某些形式的健康。地质学家发现，蛇、狮鹫、飞龙以及纹章上其他想象出来的装饰图案，都在人类被造出来之前就已灭绝的化石物种的形态里有它们的原型，因此“表明了对一种先前的有机存在状态的模糊而朦胧的认识”。印度人梦见大地驮在一头大象身上，大象驮在一只乌龟身上，乌龟又驮在一条蛇身上；虽然这也许是个无关紧要的巧合，但在这里不妨说一句：最近在亚洲发现了一只乌龟化石，大得足以驮起一头大象。我承认，我偏爱这些超越了时间和发展顺序的野性的幻想。它们是智力最崇高的消遣。山鹑爱吃豌豆，但不爱吃那些和她一起下锅的豌豆。

总之，一切好的东西都是野性的、自由的。一段音乐里有某种东西，不管是乐器奏出的还是人声唱出的——比如夏夜里的一声军号——它凭着它的野性，说句不带讽刺的话，让我想起野兽在它们原生的森林里发出的叫声。那是我所能理解的它们的那一份野性。给我野性的人做朋友和邻居吧，不要驯顺的人。野蛮人的野性，不过是好人和恋人相遇时那种令人敬畏的野性的一个模糊的象征。

我甚至喜欢看到家畜重新维护它们天生的权利——任何证据，证明它们并没有完全失去原初的野性习性和活力；比如我邻居的母牛早春时冲出牧场，大胆地游过河去，那是一股冰冷灰暗的流水，二十五或三十杆宽，因融雪而上涨。那是野牛在横渡密西西比河。在我眼里，这番壮举给那群牛——它们本已很有尊严——又增添了几分尊严。本能的种子保存在牛马厚厚的皮下，就像种子保存在大地的腹中，不知能保存多久。

牛的任何嬉闹都出人意料。有一天，我看见一群十来头阉牛和母牛跑来跑去，笨拙地蹦跳嬉戏，像巨大的老鼠，甚至像小猫。它们摇着头，翘起尾巴，在一座小山上冲上冲下；从它们的角，也从它们的活跃，我看出了它们与鹿族的亲缘。可是，唉！突然一声响亮的“吁！”就会立刻浇灭它们的热情，把它们从鹿肉降为牛肉，使它们的身侧和筋腱像火车头一样僵硬。除了那恶者，谁曾对人类喊过“吁！”呢？确实，牛的生活，像许多人的生活一样，不过是一种火车头式的移动；它们一次只挪动半边身子，而人凭着他的机器，正在和马和牛半路相迎。凡是被鞭子碰过的地方，从此就麻痹了。谁会想到去说灵活的猫族中哪一只的“半边”，就像我们说“半边牛肉”那样呢？

我很高兴，马和小公牛在被弄成人的奴隶之前必须先被驯服，而人自己在变成社会顺从的成员之前，也还有些“野燕麦”没有撒完。毫无疑问，并不是所有的人都同样适合被文明化；大多数人像狗和羊一样，因为遗传的禀性而驯顺，但这不能成为理由，要把其他人的天性也摧折，好把他们降到同样的水平。人大体上是相似的，但他们被造成许多个，是为了能够各不相同。如果要派一种低下的用场，一个人和另一个人差不多或者完全一样好；如果要派一种高尚的用场，就要看个人的卓越了。任何人都能堵住一个洞来挡风，但没有别人能派上这个比喻的作者所派上的那种罕见的用场。孔子说：“虎豹之鞟，犹犬羊之鞟。”但真正的文化的本分，不是驯服老虎，正如不是使羊变得凶猛；而把它们的皮鞣了做鞋，也不是它们最好的用处。

当我浏览一份外国语言的人名单，比如军官名单，或者就某个专题写过书的作者名单时，我又一次想到，名字里什么也没有。比如缅希科夫这个名字，在我听来，并不比一根胡须更有人味，它也可以属于一只老鼠。波兰人和俄国人的名字在我们听来是什么样，我们的名字在他们听来也就是什么样。仿佛他们是用孩子们的顺口溜起的名——Iery-wiery ichery van, tittle-tol-tan。我在心里看见一群野生的动物在大地上蜂拥，牧人给每一只都贴上了一个用他自己的方言发出的野蛮的声音。人的名字，当然和博斯、特雷这些狗的名字一样廉价，一样没有意义。

我想，如果人只按大类来命名，按人们对他们的了解来命名，对哲学会有些好处。只需要知道属，也许再加上种族或变种，就能知道个体了。我们不准备相信，罗马军队里的每一个普通士兵都有他自己的名字——因为我们并不认为他有他自己的性格。目前，我们唯一真正的名字是绰号。我认识一个男孩，因为他特别有劲，玩伴们叫他“闯将”，这个绰号理所当然地取代了他的教名。有些旅行者告诉我们，一个印第安人起初并没有人给他起名字，而是要去赢得一个名字，他的名字就是他的名声；在有些部落里，他每立一次新功，就获得一个新名字。一个人既没有赢得名字也没有赢得名声，却仅仅为了方便而顶着一个名字，那是可怜的。

我不会让仅仅是名字替我作出区分，尽管有这些名字，我照样把人看成一群一群的。一个熟悉的名字，并不能让一个人对我变得不那么陌生。它可能被安在一个野人身上，而他暗地里保留着自己在树林里赢得的野性的称号。我们心里有一个野蛮人，也许在什么地方，记录着一个野蛮的名字，那才是我们的。我看见我的邻居，顶着威廉或者埃德温这样熟悉的称呼，脱外套时就把它一起脱掉了。他睡着的时候，发怒的时候，被什么激情或灵感唤起的时候，这名字都不附在他身上。在那样的时刻，我仿佛听见他的某个族人，用某种拗口的或者悦耳的语言，叫出他原初的野性的名字。

这就是我们这位广大的、野蛮的、咆哮的母亲，自然，躺在我们四周，那样美丽，又像母豹那样爱她的孩子；可我们这么早就被从她的怀里断了奶，交给社会，交给那种完全只是人对人的相互作用的文化——一种近亲繁殖，它至多只能产生一种纯然英国式的贵族，一种注定很快就会走到尽头的文明。

在社会中，在人类最好的制度中，很容易看出某种早熟。我们本该还是正在成长的孩子，却已经是小大人了。给我一种从草地上运来大量淤泥、使土壤加深的文化吧——而不是那种只信赖催热的肥料、改良的农具和耕作方法的文化！

我听说过许多可怜的、眼睛酸痛的学生，如果他们不熬到那么晚，而是老老实实地睡足一个傻瓜该睡的分量，无论在智力上还是体格上，都会长得更快。

甚至给人知识的光，也可能过量。法国人涅普斯发现了“光化性”，即太阳光线中产生化学效应的那种力量；他发现花岗岩、石头建筑和金属雕像“在阳光照耀的时辰里都同样受到破坏性的作用，要不是自然有同样奇妙的安排，它们很快就会在宇宙中最微妙的力量那轻柔的触碰下毁灭”。但他观察到，“那些在白天经历了这种变化的物体，在夜间的时辰里，当这种刺激不再影响它们时，具有恢复原状的能力”。由此人们推断，“黑暗的时辰对于无机的造物，就像我们知道夜晚和睡眠对于有机界一样必要”。连月亮也不是每夜都照耀，而是让位给黑暗。

我不愿每个人、或者一个人的每一部分都被耕作，正如我不愿大地的每一英亩都被耕作：一部分是耕地，但更大的部分会是草地和森林，它们不仅派上眼前的用场，还通过它们所养育的草木一年一年的腐烂，为遥远的未来准备着腐殖土。

孩子要学的字母，除了卡德摩斯发明的那些，还有别的。西班牙人有一个好词来表达这种野性而幽暗的知识——Gramatica parda，黄褐色的语法，一种天生的机智，就来自我提到过的那只母豹。

我们听说过一个“实用知识传播会”。据说知识就是力量，诸如此类。我想，同样需要一个“实用无知传播会”，我们可以称之为“美的知识”，一种在更高的意义上有用的知识：因为我们大多数自夸的所谓知识，不就是一种自以为知道了点什么的自负吗？它夺走了我们实际的无知所带来的好处。我们所说的知识，常常是我们积极的无知；无知，则是我们消极的知识。经过多年耐心的勤勉和读报——因为科学的图书馆不就是一摞摞报纸合订本吗——一个人积累起无数事实，把它们储存在记忆里，然后，当他在人生的某个春天漫步出门，走进思想的大田野，他就像一匹马那样去吃青草，把所有的挽具都留在了马厩里。有时我要对实用知识传播会说——去吃草吧。你们吃干草已经吃得够久了。春天带着它绿色的庄稼来了。连母牛也在五月底以前被赶到乡下的牧场去了；尽管我听说过一个违背天性的农夫，一年到头把他的母牛关在牛棚里喂干草。实用知识传播会常常就是这样对待它的牲口的。

一个人的无知，有时不仅有用，而且美——而他所谓的知识，却常常比无用还糟，而且丑陋。跟哪一种人打交道最好呢——是对一个题目一无所知、并且（这是极为罕见的）知道自己一无所知的人，还是对它确实知道一些、却以为自己全都知道的人？

我对知识的渴望是时断时续的，但我想把头浸入我的脚所不知道的大气中去的渴望，却是常年不断的。我们所能达到的最高境界，不是知识，而是与智性的共鸣。我不知道这种更高的知识，是否比一种新奇而宏大的惊异更确定些——那是在突然领悟到我们先前称为知识的一切都不够时的惊异——一种发现：天地之间有许多事情，是我们的哲学里没有梦想到的。那是太阳把雾照亮。人不能在比这更高的意义上去知道，正如他不能安然无恙地平静直视太阳的脸：Ὡς τι νοῶν, οὐ κεῖνον νοήσεις——“你不会像感知某一样特定的东西那样感知它”，《迦勒底神谕》这样说。

寻找一条我们可以服从的法则，这种习惯里有某种奴性。我们可以随自己方便、为自己方便去研究物质的法则，但一种成功的生活不知道任何法则。发现一条法则，它在我们先前不知道自己被束缚的地方束缚着我们，这当然是一种不幸的发现。自由地生活吧，雾的孩子——在知识方面，我们都是雾的孩子。敢于自由生活的人，凭着他与立法者的关系，高于一切法则。《毗湿奴往世书》说：“不为束缚我们的，才是积极的义务；为解脱我们的，才是知识：其他一切义务，只能叫人疲倦；其他一切知识，只是工匠的机巧。”

值得注意的是，在我们的历史中，事件或危机是多么少，我们的心灵受过的磨炼多么少，我们有过的经历多么少。我很想确信自己正在迅速而茂盛地生长，哪怕我的生长会扰乱这种沉闷的平静——哪怕这要在漫长、黑暗、闷热的夜里或者阴郁的季节里挣扎着进行。要是我们的全部生活甚至是一场神圣的悲剧，而不是这样琐屑的喜剧或闹剧，那就好了。但丁、班扬等人的心灵，似乎比我们受过更多的磨炼：他们接受过一种我们的区立学校和大学所想不到的教养。甚至穆罕默德，尽管许多人听见他的名字会尖叫，他所拥有的值得为之而活、啊，值得为之而死的东西，也比那些人通常所有的多得多。

难得有那么一回，某个思想来访一个人，也许他正走在铁路上，那时，火车开过去他确实也听不见。但很快，凭着某条无情的法则，我们的生活开过去了，火车又回来了。

“轻柔的风啊，你看不见地漫游， / 吹弯了风暴的洛拉周围的蓟草， / 你这多风山谷里的旅人， / 为什么这么快就离开了我的耳朵？”

几乎所有的人都感到有一种吸引力把他们拉向社会，却很少有人被强烈地吸引向自然。在与自然的关系上，在我看来，人们尽管有他们的种种技艺，大多比动物还低。这种关系不常像动物那样是一种美的关系。我们中间对风景之美的欣赏是多么少啊！我们得听人告诉我们，希腊人把世界叫作 Κόσμος，美，或者秩序，但我们并不清楚地看出他们为什么这样叫，至多只把它当作一个有趣的语文学事实。

就我自己来说，我觉得在自然方面，我过着一种边境上的生活，住在一个世界的边界上，我只是偶尔、短暂地闯进去一下；我对那个我似乎要退入其疆土的国家的爱国心和忠诚，是一个边境劫掠者的爱国心和忠诚。为了一种我称之为自然的生活，我愿意跟着哪怕是一团鬼火，穿过无法想象的泥沼和泥潭，但还没有哪个月亮或萤火虫给我指出通往那里的堤道。自然是一种如此广大而普遍的人格，我们从来没有见过她的任何一个面貌。在环绕我家乡小镇的那些熟悉的田野里散步的人，有时会发现自己到了另一片土地上，与田主们地契上描述的不同，仿佛到了实际的康科德边界上的某块遥远的田地，在那里，康科德的管辖权停止了，“康科德”（和谐）这个词所暗示的观念也不再被暗示了。这些我亲自测量过的农场，这些我亲手立下的地界，仍然朦胧地显现着，像隔着一层雾；但它们没有化学药剂来定影；它们从玻璃的表面上褪去，而画家画下的那幅画，从下面朦胧地显现出来。我们通常所熟悉的世界，不留下任何痕迹，也不会有任何纪念日。

前几天下午，我在斯波尔丁的农场散步。我看见落日照亮了一片庄严的松林的对面一侧。它金色的光线散乱地射进林中的走廊，就像射进某座高贵的大厅。我觉得，仿佛有某个古老的、十分可敬的、闪闪发光的家族，在这片叫作康科德的土地的那一部分定居了下来，我却不知道——太阳是他们的仆人——他们没有进入村里的社交圈——也没有人去拜访过他们。我看见他们的园林，他们的游乐场，在树林那边，在斯波尔丁的蔓越莓草地上。松树一边生长，一边为他们提供山墙。他们的房子并不显露在视野里；树木从房子中间长过去。我不知道自己是否听见了一种压低了的欢笑声。他们似乎斜倚在阳光上。他们有儿有女。他们都很好。农夫的车道径直穿过他们的大厅，却一点也没有打扰他们，就像有时透过倒映的天空，可以看见池塘浑浊的底。他们从没听说过斯波尔丁，也不知道他是他们的邻居——尽管我听见他赶着牲口穿过那座房子时吹着口哨。没有什么能比得上他们生活的宁静。他们的纹章只是一片地衣。我看见它画在松树和橡树上。他们的阁楼在树梢上。他们不属于任何党派。没有劳作的声音。我没有察觉他们在织布或纺纱。然而，当风停息、听觉也消失了的时候，我确实察觉到一种可以想象的最细微、最甜美的音乐般的嗡嗡声——像五月里远处的一个蜂房，那也许就是他们思考的声音。他们没有闲散的念头，外面的人也看不见他们的工作，因为他们的勤劳并不像困在树结和瘤节里的那样。

但我发现很难记住他们。即使现在，我一边说着、一边努力回想他们、让自己定下神来，他们也在无可挽回地从我心里褪去。只有经过长久而认真的努力，回想起我最好的思想之后，我才重新意识到他们与我同住。要不是有这样的家族，我想我会搬出康科德。

在新英格兰，我们常说，每年来访我们的鸽子越来越少了。我们的森林没有给它们提供坚果。似乎，每年来访每个正在成长的人的思想也越来越少了，因为我们心中的树林已被毁坏——卖去喂养不必要的野心之火，或者送进了磨坊——几乎没留下一根小枝给它们栖息。它们不再在我们这里筑巢繁殖了。也许在某个比较温和的季节，一片淡淡的影子掠过心灵的风景，那是某个思想在它春天或秋天的迁徙中，翅膀投下的影子；可是抬头一看，我们却看不出那思想本身的实体。我们长着翅膀的思想变成了家禽。它们不再翱翔，只达到上海鸡和交趾支那鸡那样的伟大。你听说的那些伟——大——的思想，那些伟——大——的人！

我们紧贴着大地——我们多么难得向上攀登！我想我们可以把自己再升高一点。至少，我们可以爬一棵树。有一次，我在爬树中得到了好处。那是一棵高大的白松，在一座小山的顶上；尽管我沾了一身松脂，却也得到了丰厚的报偿，因为我在地平线上发现了以前从未见过的新的山——多了那么多的大地和天空。我本可以在树脚下走上七十年，却一定永远不会看见它们。但最重要的是，我发现在我周围——那时将近六月底——只在最高的枝梢上，有几朵微小而精致的红色球果状的花，那是白松向着天空开放的雌花。我立刻把最高的那根枝梢带到村里，给在街上走着的陌生的陪审员们看——因为那是开庭的一周——又给农夫、木材商、樵夫和猎人看，没有一个人以前见过这样的东西，他们惊奇得就像看见一颗掉下来的星星。还说什么古代的建筑师把柱顶上的作品完成得像下部更显眼的部分一样完美！自然从一开始就只向着天空展开森林里微小的花朵，在人的头顶之上，不被他们看见。我们只看见草地上我们脚下的花。千百年来，松树每年夏天都在树林最高的枝梢上开出它们精致的花，既在自然的红皮肤孩子头顶之上，也在她的白皮肤孩子头顶之上；然而这片土地上几乎没有一个农夫或猎人见过它们。

最重要的是，我们不能不活在当下。在一切凡人之中，最有福的，是那个不把流逝的生命中的任何一刻浪费在回忆过去上的人。除非我们的哲学听见我们视野之内每一个农家院里的公鸡啼叫，否则它就是迟到了。那声音通常提醒我们，我们在自己的职业和思维习惯里正变得生锈而陈旧。它的哲学比我们的来得更晚近。它所暗示的东西，是一部更新的约书——依照此刻的福音。它没有落在后头；它起得早，一直早早地醒着，处在它所在的地方，就是合乎时令，处在时间的最前列。那是自然的健康与健全的表达，是对全世界的夸耀——像一股迸发的泉水那样的健康，一道新的缪斯之泉，来庆祝时间的这最后一刻。在它住的地方，没有通过什么逃奴法。自从上次听见那声啼叫以来，谁没有多次背叛过他的主人呢？

这只鸟的歌的好处，在于它毫无哀怨。歌手很容易让我们落泪或发笑，但能在我们心里激起一种纯粹的清晨的欢乐的人，在哪里呢？当我心情沮丧，在一个星期天打破我们木板人行道上那可怕的寂静，或者，也许是在守丧的人家守夜的时候，我听见远处或近处一只小公鸡啼叫，我就对自己想：“不管怎样，我们当中总有一个是好好的”——于是心头猛地一涌，回到了自己的感官里。

去年十一月的一天，我们看到了一次非凡的日落。我在一片草地上散步，那是一条小溪的源头；那是寒冷灰暗的一天，太阳终于在落山之前，到了地平线上一层晴朗的天空，最柔和、最明亮的晨光一般的阳光，洒在干枯的草上，洒在对面地平线上的树干上，洒在山坡上灌木橡树的叶子上，而我们的影子在草地上向东拉得长长的，仿佛我们是那光束中仅有的尘埃。那是一种我们片刻之前都无法想象的光，空气也那样温暖宁静，那片草地成为乐园已经什么都不缺了。当我们想到，这并不是一次孤立的、永不重现的现象，而是会永远、永远地发生，在无数个傍晚，去鼓舞、安慰将来最后一个走在那里的孩子，它就更加辉煌了。

太阳落在某片僻静的草地上，那里看不见一所房屋；它落下时，带着它慷慨洒向城市的全部光辉与壮丽，也许落得前所未有地美；那里只有一只孤独的白尾鹞，翅膀被它镀上金色，或者只有一只麝鼠从它的小屋里向外张望，沼泽中间有一条黑色纹理的小溪，刚刚开始蜿蜒，绕着一截朽烂的树桩慢慢流转。我们走在那样纯净明亮的光里，它给枯草和落叶镀上金色，那样柔和、那样宁静地明亮，我想我从未沐浴过这样一股金色的洪流，它没有一丝涟漪，没有一点声响。每一片树林、每一处高地的西侧，都像极乐之境的边界一样闪着光，而我们背上的太阳，像一位温和的牧人，在傍晚赶着我们回家。

我们就这样向着圣地闲逛而去，直到有一天，太阳照得比以往任何时候都更明亮，也许会照进我们的心灵，用一道伟大的、唤醒的光照亮我们的一生，像秋天河岸上的阳光一样温暖、宁静、金黄。
