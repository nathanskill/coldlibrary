## 摘要

资深 Python 人 Tim Peters 言简意赅地道出了“仁慈的终身独裁者”（BDFL）为 Python 设计定下的指导原则，共二十条格言，其中只有十九条被写了下来。

## Python 之禅

优美胜于丑陋。

明确胜于隐晦。

简单胜于复杂。

复杂胜于凌乱。

扁平胜于嵌套。

疏朗胜于稠密。

可读性很重要。

特例也没有特殊到可以打破规则。

尽管实用胜过纯粹。

错误绝不应悄无声息地放过。

除非明确地让它安静。

面对含糊，拒绝猜测的诱惑。

应当有一种——最好只有一种——显而易见的做法。

尽管这种做法起初未必显而易见，除非你是荷兰人。

现在做胜于永远不做。

尽管永远不做往往胜于*马上*就做。

如果实现难以解释，那它是个坏主意。

如果实现易于解释，那它也许是个好主意。

命名空间是个绝妙的主意——让我们多用一些！
