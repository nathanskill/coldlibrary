## SQLite 属于公有领域

SQLite 的全部代码和文档都已由作者们献入公有领域。所有代码作者，以及他们所供职公司的代表，都签署了宣誓书，把各自的贡献献入公有领域；这些宣誓书的原件保存在 Hwaci 公司总部的防火保险柜里。所有贡献者都是允许把创作献入公有领域的国家的公民。任何人都可以自由地复制、修改、发布、使用、编译、出售或分发原始的 SQLite 代码，无论是源代码形式还是编译后的二进制形式，可用于任何目的，商业或非商业皆可，方式不限。

上一段适用于 SQLite 中可交付的代码和文档——也就是你实际打包、随更大的应用程序一起发布的那部分 SQLite 库。构建过程中用到的某些脚本（例如 autoconf 生成的“configure”脚本）可能适用其他开源许可证。但这些构建脚本中的任何内容都不会进入最终交付的 SQLite 库，因此这些脚本的许可证不应成为你评估复制和使用 SQLite 库之权利时的考虑因素。

SQLite 中所有可交付的代码都是从零写起的。没有任何代码取自其他项目或开放的互联网。每一行代码都能追溯到它最初的作者，而这些作者全都有存档的公有领域献辞。所以 SQLite 的代码库是干净的，没有混入来自其他项目的受许可证约束的代码。

## 开源，但不开放贡献

SQLite 是开源的，意思是你想复制多少份都可以，拿这些副本做什么都可以，没有限制。但 SQLite 不是“开放贡献”的。为了让 SQLite 始终留在公有领域，确保代码不被专有或受许可证约束的内容污染，本项目不接受那些尚未提交宣誓书、把自己的贡献献入公有领域的人所提交的补丁。

SQLite 中的所有代码都是原创的，专门为 SQLite 而写。没有任何代码是从互联网上来历不明的地方复制来的。
