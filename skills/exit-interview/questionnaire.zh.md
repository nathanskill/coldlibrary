# 整理谈话：纸质问卷

冷冻图书馆 · 规范 v0.1 · CC0-1.0 · 不需要 AI

## 开始之前

这份问卷帮你亲手写出交接清单的第一版。一共三十道题，按 `COLDLIBRARY.md` 的十个章节分组。能答的就答，不想答的跳过，随时可以停下。分几次写完也可以。

它不是遗嘱。你的财产按法律遗嘱或法定继承处理。

**先顾好你自己。**

- 只面向年满 18 岁的成年人。请在一个人、心情平稳的时候，按自己的意愿来写。
- 如果写的过程中，你有了结束生命的念头，请就此停下，马上找人说说。中国大陆可以拨打 12356（全国统一心理援助热线）；在美国可以拨打或发短信到 988；其他地区可以查询 https://findahelpline.com。情况紧急时，请拨打 110 或 120，或当地的急救电话。
- 冷冻图书馆不是告别工具。

**这几页纸上，不要写下面任何一样：**

- 密码或 PIN 码；
- 助记词或恢复短语；
- 私钥或份额；
- 任何金额。

你拥有的东西，只写它是什么种类、放在哪里、该问谁。

**这几页纸请私下保管。** 填好以后，它和你的工作区一样敏感。别人的名字，写个简称就够了。答案录入工作区以后，这几页纸留不留、要不要粉碎，由你决定。

## 最后的检查

- [ ] **选好了开启人。** 三位成年人，来自生活的不同部分，没有两位是同一户的。
- [ ] **问过了开启人。** 每一位都同意了，日期已经记下。
- [ ] **选好了保管方。** 如果由开启人自己保管箱子，我明白凑够人数的开启人随时都能打开它。
- [ ] **定好了时效。** 每条心愿都有适用阶段、“照办到”和“参考到”。
- [ ] **信是我亲手写的。** 一封信一个文件，用编号命名。
- [ ] **没有秘密。** 这几页纸上没有密码、PIN 码、助记词、私钥、份额或金额。
- [ ] **已经录入。** 用 `coldlibrary init` 创建了工作区，答案已经录入，`coldlibrary validate` 没有报错。
- [ ] **冷静期。** 从 `coldlibrary init` 到第一次封存，至少隔 7 天。这段时间里我又从头读了一遍。
- [ ] **份额当面交接。** 不拍照，不发聊天软件。
- [ ] **演练过了。** 用一份虚构的交接清单演练过一次。和每位开启人约定了暗号。每位开启人都知道箱子在哪里、该打给谁。
- [ ] **每年检查。** 在日历上定好一天，检查开启人、保管方和联系方式。
